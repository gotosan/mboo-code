# 术语表

## 权限

| 术语 | 英文 / 代码符号 | 含义 |
| --- | --- | --- |
| 权限模式 | `permissionMode` | 会话级开关，决定工具授权是否需要用户确认，取值见下两行。存储在 `Sessions.metadataJson` 顶层。 |
| 默认权限 | `DEFAULT` | 默认模式。工具调用按权限内核正常评估，`NEED_ASK` 时弹授权卡片等待用户决策。 |
| 完全访问 | `FULL_ACCESS` | `NEED_ASK` 自动视为 `ALLOWED`，不再弹授权卡片；`ERROR` 与内置命令黑名单照常拒绝。 |
| 权限类型 | `ToolPermissionType` | 工具声明的基础权限种类：`NONE` / `TOOL` / `READ` / `WRITE` / `COMMAND`。 |
| 权限要求 | `PermissionRequirement` | 一次工具调用产生的单个授权诉求，含类型、授权目录、范围值与当前评估结果。 |
| 权限链 | `ToolPermissionChain` | 一次工具调用的有序权限要求集合，如工作区外命令的 `WRITE -> COMMAND`。 |
| 评估结果 | `PermissionCheck` | 单个权限要求的判定：`ALLOWED`（已满足）/ `NEED_ASK`（需用户授权）/ `ERROR`（硬错误，直接拒绝）。 |
| 授权卡片 | `TOOL_APPROVAL_REQUIRED` 事件 | 前端展示的授权确认 UI，对应一个待处理的授权阶段。 |
| 单次授权 | `ALLOW_ONCE` | 仅允许当前工具调用，不持久化。 |
| 会话授权 | `ALLOW_SESSION` | 在当前会话持续有效的授权，持久化到 `metadataJson.permissions`。 |
| 授权目录 | `grantPath` | 路径型权限申请授权的规范化绝对目录，包含其子目录。 |
| 命令指纹 | `allowedCommands` 元素 | 版本化命令哈希，绑定原始命令、真实工作目录和 Shell 身份，用于 `COMMAND` 会话授权。 |
| 内置命令黑名单 | `COMMAND_PERMISSION_DENIED` | `CommandPermissionMatcher` 硬编码禁止的危险命令规则，任何模式下都不放行。 |
| 执行前复核 | `verifyFinalPlan` | 工具真实执行前重新生成权限链做最终检查，防止授权后参数被篡改。 |
| 会话工作区 | `Sessions.workspacePath` | 会话绑定的绝对目录，创建后不变；默认允许读取，写入仍需授权。 |

## 工作区

| 术语 | 英文 / 代码符号 | 含义 |
| --- | --- | --- |
| 保存工作区 | `Workspace` | 用户选择的自定义目录所对应的持久化记录，按规范化后的真实绝对路径唯一识别，用于侧边栏工作区分组。 |
| 工作区名称 | `Workspace Display Name` | 保存工作区真实绝对路径的末级文件夹名，仅用于展示，允许重名，不参与工作区唯一性判断。 |
| 工作区路径比较键 | `Workspace.pathKey` | 由真实绝对路径和当前平台路径语义生成的内部唯一键；Windows 忽略大小写，Unix-like 系统保留大小写，不直接展示。 |
| 工作区可用状态 | `WorkspaceResp.available` | 读取工作区列表时根据保存路径是否仍为可访问目录计算的展示状态，不持久化，也不改变会话归属。 |
| 默认工作区 | `Default Workspace` | 未选择自定义路径时，由后端在应用数据目录下为单个会话创建的独立目录；不生成保存工作区记录，对应侧边栏“任务”区域。 |
| 工作区归属 | `Sessions.workspaceId` | 会话在侧边栏中的显式分组关系。字段为空时归入“任务”；非空时归入对应的保存工作区。会话执行路径仍由 `Sessions.workspacePath` 保存；旧数据中无法迁移的异常路径会话是暂归“任务”的兼容例外。 |
| 待提交工作区 | `pendingWorkspacePath` | 新会话发送首条消息前的路径选择，可以改选或清除；不会创建会话，最终值决定创建后的工作区归属。 |
| 工作区删除 | `Workspace Deletion` | 删除保存工作区记录并永久删除其全部下属会话和应用内会话制品；不删除工作区对应的用户磁盘目录。 |

## 会话

| 术语 | 英文 / 代码符号 | 含义 |
| --- | --- | --- |
| 会话元数据 | `Sessions.metadataJson` | JSON 字符串，存放权限、权限模式等会话扩展数据，更新走分段锁 + CAS。 |
| 会话事件 | `SessionEvent` | 会话内追加的事件记录（JSONL），用于前端流式推送与历史回放。 |

## 上下文

| 术语 | 英文 / 代码符号 | 含义 |
| --- | --- | --- |
| 模型上下文能力上限 | `maxContextLimit` | models.dev 为当前模型提供的上下文窗口物理上限，只读，也是用户可调范围的最大值。 |
| 模型上下文偏好 | `ModelContextPreference` | 用户按供应商实际模型 ID 保存的自定义上下文窗口上限。 |
| 生效上下文上限 | `effectiveContextLimit` | 有有效模型上下文偏好时使用偏好，否则使用模型上下文能力上限；作为输入上下文圆环、压缩和硬预算的统一应用上限，不限制主模型输出。 |
| 工作区指令 | `Workspace Instructions` | 与会话工作区绑定、在主模型处理该工作区任务时持续生效的项目级行为指导。第一版由工作区根目录的 `AGENTS.md` 承载。 |
| 工作区指令快照 | `Workspace Instruction Snapshot` | 单个执行 turn 开始时读取并确定、在该 turn 内保持不变的一版工作区指令。 |
