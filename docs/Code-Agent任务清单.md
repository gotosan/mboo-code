## 目标定位

本项目目标是做一个类似 Codex 的 code agent 后端 runtime。

第一版重点不是普通聊天，而是让 agent 能在指定工作区内理解代码、调用工具、修改文件、执行命令，并且把整个过程记录成可恢复、可审计的会话事件日志。
